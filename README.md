> **A private, local AI companion that learns you over time.**
> Everything runs on your device. Nothing leaves your machine. Ever.

Quil is a **desktop AI assistant** built with Tauri + Python that runs entirely on your computer — no cloud, no API keys, no subscriptions. It's not just a chat interface. It's a system with memory, autonomy, and self-improvement built into its core.

| You are... | Quil gives you... |
|:-----------|:------------------|
| **A deep worker** | An AI that remembers context across sessions — no re-explaining |
| **Privacy-conscious** | Zero cloud dependency. Your data stays on your SSD |
| **A developer** | A reference architecture for local memory, agents, and self-improving prompts |
| **Curious about AI** | A transparent system where you can see *how* the AI thinks and learns |

**What makes it different:**

- 🧠 **7-layer memory system** inspired by human cognition — episodic, semantic, procedural, prospective, emotional, contextual, and working memory
- ⚡ **Workshop** — delegate complex tasks (e.g. "build me a resume"), Quil plans and executes them in the background while you keep chatting
- ✨ **Self-improving prompts** — every hour, Quil evaluates its own responses and rewrites its own instructions based on what works
- 🗺️ **Interactive memory graph** — a force-directed, canvas-rendered visualization of everything Quil knows about you
- 🔒 **100% private** — conversations, documents, and data never leave your machine

**Tech:** Tauri 2.0 (Rust) · Python FastAPI · Qwen3 4B via Ollama · LanceDB · SQLite · D3.js
